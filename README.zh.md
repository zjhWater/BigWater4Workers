# dsh-stand-reminder

[English](README.md) | 中文

DSH 桌面端插件：右下角常驻一个「坐在电脑前」的像素小人，每半小时提醒你站起来、喝水。

> 仓库：<https://github.com/zjhWater/BigWater4Workers> · npm 包名：`dsh-stand-reminder`

到点时小人会站起来伸懒腰，并浮出提醒卡片 + 两声提示音。点「我站起来了」重新计时，点「再过 5 分钟」稍后再催。

桌上的水杯是一条独立的线：按「每天几杯」的节奏慢慢涨满，涨满就该喝了；点一下杯子就清空重新涨，跟站立提醒互不干扰。

整个提醒是页面内的计时器，不投递消息、不唤醒模型、不消耗 token，也不联网。

## 一天怎么用

1. 打开 DSH，小人翘着腿搭在桌上，屏幕是黑的、中间一个红色电源键，角标写「收工」。
2. 点一下显示器 = 开机，开始计时；之后到点就会提醒你站起来、喝水。
3. 要离开一会儿？点小人，他起身走出画面，只留一张空椅子；回来点椅子，他走回座位继续。
4. 下班点一下显示器 = 关机收工，屏幕上亮起红色电源键，小人把腿翘到桌上，当天不再提醒；当天的累计（工作分钟、杯数、水杯）会保留着，**下次开机时统一归零**，从干净的一天开始。

## 提醒规则

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 提醒间隔 | 30 分钟 | 设置里 5–180 分钟 |
| 工作时段 | 09:00–18:00 | 时段外不提醒，小人显示「休息」 |
| 午休 | 12:00–13:30 | 可关；午休期间到期会顺延到午休结束后 |
| 提示音 | 开 | 两声短音，浏览器未交互过时自动静音 |
| 提示音量 | 70% | 0–100%，设置里拖动滑块；拖动时实时保存，松手会试听一声 |
| 画面大小 | 100% | 基准尺寸 = clamp(160px, min(窗口宽, 高) × 26%, 320px)，跟窗口一起变大变小（和小鲸鱼同一套思路）；滑块/滚轮在基准上再乘 50%–300%，只缩放像素场景，角标/卡片/面板字号不变 |
| 时间字号 | 32px | 20–48px，只影响角标文字大小；设置面板跟随 Harness 本体字体 |
| 喝水提醒 | 开 | 面板显示「已喝 X / 目标 N 杯」，默认 8 杯可改；水杯每约 56 分钟涨满一杯（有效工作分钟 ÷ 目标杯数），人在电脑前就蓄水，不分工作时段。依据《中国居民膳食指南（2022）》成年男性 1700ml/天、女性 1500ml/天 |
| 工作记录 | 显示 | 关闭后不显示「今日工作」那一行，时长按开机时间自动累计 |

## 交互

| 点哪里 | 做什么 |
| --- | --- |
| 显示器 | 开 / 关机。关机 = 收工，屏幕显示红色电源键，小人翘腿；再点重新开机 |
| 小人 | 离开电脑（起身走出画面），只留空椅子 |
| 椅子 | 回来工作（走回座位并重新计时） |
| 桌上的水杯 | 当作喝了一杯：水位清零、今日杯数 +1，重新慢慢涨满 |
| 悬停后出现的三横按钮 | 打开设置面板（和鲸鱼挂件同款样式） |
| 拖小人 | 换位置；左右边缘 10%、底部 15% 内会吸附，贴左时整个场景水平镜像 |
| 悬停 + 滚轮 | 每格放大 / 缩小 5% |

卡片只有三个按钮：`我站起来了`（重新计时）、`再过 5 分钟`、`不再提醒`。按 Esc 关闭卡片或面板。

边界行为：

- 卡片 60 秒没操作自动收起，小人坐回去；若一直没人理，10 分钟后再催一次，之后回到正常间隔。
- 下班前 10 分钟不再触发，避免刚站起来就到点下班。
- 电脑休眠 / 页面关太久（错过 5 分钟以上）不补弹，安静地往后顺延。
- 「不再提醒」暂停到下一个工作日 09:00，之后自动恢复。
- 每天首次打开自动回到「未开机」，水杯和工作时长清零。
- 多个标签页之间用 localStorage 事件同步状态。

## 迷你模式（收进输入框）

点挂件右上角的「—」按钮，整个小人收起来，改成输入框底部的一排杯子：

- 杯子数量 = 今天的喝水目标（默认 8 个）
- 灰色 = 还没轮到；蓝水从底部涨 = 正在蓄水
- 蓄满后 5 分钟里从 1 倍放大到 2 倍，并轻微呼吸、响一声
- 点杯子 = 喝掉：水清零、恢复原尺寸、变透明，下一杯接着蓄水
- 鼠标移到杯排上，右侧出现两个小按钮：设置、「+」回到完整挂件
- 按住杯排任意位置拖动超过 4px 就变成拖动，松手记住位置；双击杯排恢复成跟随输入框

迷你模式下站立提醒停用，只保留喝水这条线。杯排跟随输入框位置，窗口缩放、页面滚动都会贴住。

## 数据

本地一份 `localStorage`（`dsh-stand-reminder:v1`）+ 宿主侧一份 JSON（`~/.dsh/dsh-stand-reminder.json`，通过插件自己的 `/dsh-stand-reminder/state` 路由读写）。之所以要宿主那份：DSH 每次启动端口都会变，`localStorage` 按端口隔离，只靠它会每次开局都是空存档，位置也跟着回到默认。

内容是设置、下次提醒时间、暂停截止时间、开关机与离座状态、喝水进度 / 工作时长、挂件与杯排位置。只在本机，不上传。

## 安装

从 npm 安装（推荐）：在 DSH 的「插件」页搜索 `dsh-stand-reminder`，或让会话里的 plugin_manager 装 npm 包：

```
plugin_manager install_bundle  target = dsh-stand-reminder
```

装完**完全退出客户端再打开**，右下角就能看到小人。

本地开发用 `link:` 指向源码目录：

```
plugin_manager install_bundle  target = link:D:\path\to\dsh-stand-reminder
```

卸载：在插件管理里 remove 该 bundle。

## 开发

```
dsh-stand-reminder/
├─ package.json       dsh.bundle.patch 指向 cordis.patch.yml
├─ cordis.patch.yml   插入 dsh-stand-reminder 条目
├─ lib/index.js       宿主侧：注入 <script> 行 + 提供前端静态文件
├─ assets/client.js   前端：UI + 状态机（改完刷新页面即生效）
└─ test/              本地预览与测试工具
```

- 宿主侧 `lib/index.js` 监听 `webserver/index-inject` 往页面塞一行内联脚本，再用 `webServer.register` 以 `/dsh-stand-reminder/client.js` 提供前端文件（按 mtime 读取，`no-store`）。改 `lib/index.js` 需重启客户端；改 `assets/client.js` 刷新页面即可。
- 状态机：`boot`（未开机）→ `sit` → `stand`（提醒）→ `leaving` / `away` / `returning`（离开与回来）→ `off`（收工翘腿）；另有 `paused`、`rest` 两种不提醒的中间态。
- 角标只显示三种状态，和画面上的动作严格对应：

| 画面动作 | 角标 | 对应模式 |
| --- | --- | --- |
| 坐着敲键盘 / 站起来伸懒腰 / 举杯喝水 | `工作` | `sit` / `stand` / `sip` / `rest` |
| 起身走开、空椅子、走回来 | `离开` | `leaving` / `away` / `returning` |
| 翘腿搭桌上、屏幕黑 | `收工` | `off` / `boot` / `paused` |

角标不带时间，具体下次提醒时刻在设置面板底部提示和挂件 tooltip 里。

- `test/preview.html`：直接用浏览器打开，插件会挂到普通页面上，左上角有「开机/收工、触发提醒、离开/回来、喝一杯、打开设置、清空状态」。支持 `?mode=boot|away|off|stand`、`?scale=140`。
- `test/render_scene.py`：不依赖浏览器，把 `assets/client.js` 里的 SVG 按像素栅格化成 PNG，检查坐 / 站 / 走 / 离座 / 未开机 / 翘腿六种画面。运行：

```
python test/render_scene.py    # 需要 Pillow
```

- 断测：先在仓库根目录 `npm install`（只装 jsdom 这个开发依赖，不会打进安装包），然后：

```
npm test          # 顺序跑下面三个
node test/dom-smoke.cjs       # 前端全流程：挂载、开关机、点小人/椅子、喝水、缩放、吸附镜像、迷你模式
node test/state-smoke.cjs     # 宿主侧存档路由：GET/PUT、坏 JSON、405
node test/hydrate-smoke.cjs   # 启动读档：迷你形态、位置不丢、当天杯数与工时恢复
```
